# Tamil Voice Agent with Tamil Turn Detection

A real-time Tamil voice agent on [Pipecat](https://docs.pipecat.ai) using [Sarvam AI](https://docs.sarvam.ai) for STT, LLM and TTS, with an end-of-turn detection model trained on Tamil.

## Why

A voice agent has to decide, at every pause, whether the caller has finished speaking. Pipecat answers this with a semantic turn detector and runs `LocalSmartTurnAnalyzerV3` **by default**.

The released Smart Turn v3 weights cover 23 languages and **Tamil is not one of them**. A Tamil agent built on the defaults therefore runs a turn detector that was never trained on Tamil prosody.

This recipe points the same analyzer at a Tamil checkpoint. One argument, no new services.

## Stack

| | |
|---|---|
| Turn detection | `santhosh-005/smart-turn-tamil` (int8 ONNX, 8.7 MB, CPU) |
| Speech-to-text | Sarvam Saaras v3 (`saaras:v3`) |
| LLM | Sarvam `sarvam-105b` |
| Text-to-speech | Sarvam Bulbul v3 (`bulbul:v3`) |
| Transport | Daily or browser WebRTC |

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env      # then add your key from https://dashboard.sarvam.ai
```

Open `tamil_turn_detection.ipynb` and run the cells. It writes `agent.py`, then:

```bash
python agent.py
```

The agent creates a Daily room and prints a URL. Open it, speak Tamil, and pause mid-sentence: the agent should wait rather than cut in.

## The one change

```python
context_aggregator = LLMContextAggregatorPair(
    context,
    user_params=LLMUserAggregatorParams(
        vad_analyzer=SileroVADAnalyzer(),
        user_turn_strategies=UserTurnStrategies(
            stop=[TurnAnalyzerUserTurnStopStrategy(
                turn_analyzer=LocalSmartTurnAnalyzerV3(
                    smart_turn_model_path=model_path
                )
            )]
        ),
    ),
)
```

Without `user_turn_strategies`, Pipecat builds the same strategy with the default Smart Turn v3 weights.

## The model

A fine-tune of [Smart Turn v3](https://github.com/pipecat-ai/smart-turn) on Tamil telephone speech. Scored on 4,168 held-out clips from 30 calls never used in training:

| | accuracy | ROC-AUC |
|---|---|---|
| always assume "finished" | 63.08% | 0.500 |
| Smart Turn v3.2, zero-shot on Tamil | 70.30% | 0.751 |
| **smart-turn-tamil, tiny int8** | **83.71%** | **0.905** |
| smart-turn-tamil, base int8 | 86.13% | 0.921 |

Trained on 18,485 labelled turn boundaries from 116 real Tamil two-party telephone conversations, derived from [SPRING-INX Tamil R1](https://arxiv.org/abs/2310.14654) (SPRING Lab, IIT Madras, CC BY 4.0). 
Real narrowband telephone audio, not TTS.

- Model: https://huggingface.co/santhosh-005/smart-turn-tamil
- Dataset: https://huggingface.co/datasets/santhosh-005/tamil-eot
- Method and benchmarks: https://github.com/santhosh-005/tamil-eot

Weights are BSD-2-Clause; the dataset is CC BY 4.0.

## Notes

- `smart_turn_model_path` wants the `.onnx` **file**, not its directory. Passing
  a directory raises `INVALID_PROTOBUF: Protobuf parsing failed`.
- On Pipecat 1.7, `language=` and `target_language_code=` at the top level of the
  Sarvam services are no longer read. Language must go inside
  `SarvamSTTService.Settings(...)` and `SarvamTTSService.Settings(...)`.
- `agent.py` is generated by the notebook and is gitignored.
